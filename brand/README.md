# Эмблема AzizDubaiGuide — единственный эталон

![](logo_source.jpg)

- `logo_source.jpg` — оригинал от владельца. Не редактировать.
- `logo_aziz.png` — эмблема, вырезанная из оригинала: белая надпись **AzizDubaiGuide** + Бурдж-Халифа + пальма + линия,
  прозрачность ровно как в оригинале (≈61 %). Прозрачный фон, 2964×660.
- `place_logo.py` — единственный способ поставить эмблему в кадр (только масштаб и позиция).

## Правила (без исключений)

1. Эмблема везде одна и та же: этот файл без изменений.
2. Нельзя: добавлять «@», менять цвет или прозрачность, добавлять тени, обводки, подложки, свечения, растягивать по одной оси,
   перерисовывать шрифтом или кодом.
3. Можно только равномерно масштабировать и выбирать место в кадре.
4. На персонажах и животных эмблему и надписи с брендом не размещать.
5. Ник в тексте (подписи, описания) пишется `@AzizDubaiGuide` — это текст, не эмблема.
