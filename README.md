# Money & Tenses Test

Интерактивная проверочная работа по английскому: три варианта (B1, B1, B1+).

Темы: фразы про деньги, сравнения (the… the…, the same as, as…as, not as…as),
прилагательные и глаголы с предлогами, а также Simple, Continuous, Perfect и Perfect Continuous.

- `index.html` — весь сайт в одном файле, открывается в любом браузере (или через GitHub Pages).
- Задания с пропусками, выбором ответа и трансформациями проверяются автоматически.
- Говорение и письмо оценивает учитель (баллы выставляются прямо в задании).
- «Режим учителя» вверху показывает ключи.
