# Как подключить Tripster, Instagram и WhatsApp-каталог

Все подключения делаются один раз в настройках облачного окружения `My_project`.
Ключи и пароли в чат и в репозиторий не пишем: они вводятся только в форме настроек.

Запросы на доступ мобильное приложение Claude сейчас показать не может. Поэтому настройку
удобнее сделать с компьютера: открыть эту сессию на claude.ai/code, либо обновить приложение.

## Где находятся настройки

Сессия на claude.ai → меню облачного окружения в заголовке сессии → `My_project` → Edit.
Там два раздела: разрешённые сайты (Allowed hosts) и сетевые секреты (Network secrets).

## 1. Tripster

Нужен тот же API-ключ, который подключали в другой переписке (он есть в коде бота).

1. В разделе Network secrets добавить секрет:
   - Host: `experience.tripster.ru`
   - Тип: Bearer / ключ в заголовке
   - Header: `Authorization`
   - Prefix: `Token` `[УТОЧНИТЬ: посмотреть в коде бота, как именно передаётся ключ]`
   - Value: сам ключ
2. Сохранить и написать в чат «ключ Tripster добавил».

После этого агенты читают программы, цены, расписание и заказы напрямую.

## 2. Instagram: официальный способ через Meta

Читать чужие аккаунты, войдя под вашим логином, агенты не будут: Instagram за это блокирует,
а пароль пришлось бы хранить в облаке. Есть официальный способ — Instagram Graph API,
функция Business Discovery. Она отдаёт по любому бизнес- или авторскому аккаунту: число
подписчиков, список публикаций, лайки, комментарии и просмотры видео. Свою статистику
(охваты, сохранения, переходы) тот же ключ отдаёт полностью.

Что сделать:

1. Перевести Instagram в профессиональный аккаунт (Настройки → Тип аккаунта → Бизнес).
2. Создать страницу Facebook и привязать к ней Instagram (Настройки → Центр аккаунтов).
3. На developers.facebook.com создать приложение типа Business и добавить продукт
   Instagram (API with Facebook Login).
4. В Graph API Explorer выбрать приложение, выдать права `instagram_basic`,
   `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement` и получить токен.
5. Обменять его на долгий токен (живёт 60 дней) в Access Token Debugger → Extend.
6. В окружении `My_project`:
   - в Allowed hosts добавить `graph.facebook.com`;
   - в Network secrets добавить секрет: Host `graph.facebook.com`, Header `Authorization`,
     Prefix `Bearer`, Value — токен.
7. Написать в чат «токен Instagram добавил».

Ограничения: видны только бизнес- и авторские аккаунты (у гидов и агентств они почти всегда
такие); сторис чужих аккаунтов недоступны; токен надо обновлять раз в 60 дней. Точные
названия прав и шаги сверить с документацией Meta на момент настройки `[ПРОВЕРИТЬ]`.

Запасной вариант без настройки: приложение Claude на компьютере с расширением для Chrome.
Оно работает в вашем браузере, где вы уже вошли в Instagram, и видит то же, что и вы. Это
отдельная сессия на компьютере, а не облачная.

## 3. Каталог WhatsApp

В Allowed hosts добавить: `wa.me`, `www.whatsapp.com`, `web.whatsapp.com`,
`static.whatsapp.net`. Каталог может всё равно не открыться без приложения WhatsApp. Тогда
самый простой путь — экспорт: открыть каталог, по каждой позиции скопировать название, цену
и описание в одну заметку и прислать текстом, либо завести лист «Каталог» в Google-таблице.
